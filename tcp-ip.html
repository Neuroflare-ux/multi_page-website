PROTOCOL
// Term 02 — TCP/IP

Transmission Control Protocol / Internet Protocol

The foundational suite of communication protocols that governs how data is transmitted across interconnected networks — the backbone of the modern internet.

// The TCP/IP four-layer model governing internet communication
Definition

TCP/IP is a suite of communication protocols used to interconnect network devices on the internet. TCP defines how applications can create channels of communication across a network, while IP defines how to address and route each data packet so it arrives at the correct destination.

Developed in the 1970s by Vint Cerf and Bob Kahn, TCP/IP is often referred to as the "language of the internet." Every device on the internet uses TCP/IP to communicate.

The Four Layers
📱
Application Layer
Protocols like HTTP, FTP, DNS, and SMTP that applications use to exchange data.
🔄
Transport Layer
TCP and UDP — manages end-to-end data delivery, ordering, and error correction.
🗺️
Internet Layer
IP — handles addressing, routing packets across different networks.
🔌
Network Access
Ethernet, Wi-Fi — physical transmission of data over the hardware medium.
TCP vs UDP

TCP (Transmission Control Protocol) establishes a reliable, ordered connection. It guarantees that packets arrive, and in the correct sequence — essential for web pages, emails, and file downloads.

UDP (User Datagram Protocol) is connectionless and faster but doesn't guarantee delivery. It's used for real-time applications like video calls and online gaming where speed matters more than perfect reliability.

IP Addressing

Why It Matters

Without TCP/IP, the internet as we know it would not exist. It is the universal agreement that allows billions of diverse devices — smartphones, servers, IoT sensors — to communicate seamlessly across the globe.
