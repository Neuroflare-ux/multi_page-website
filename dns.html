Domain Name Server (DNS)

What is DNS?

DNS (Domain Name System) translates human-friendly domain names like www.google.com into IP addresses that computers use to find each other on the internet.

Why is DNS Needed?

Computers communicate using numbers (IP addresses), not names. DNS acts like a phone book — you look up a name and get the number.

How it Works

When you type a website address, your computer asks a DNS server for the matching IP address. The DNS server responds with the address, and your browser connects to that server.
