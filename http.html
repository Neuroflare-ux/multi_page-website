Hypertext Transfer Protocol (HTTP)

What is HTTP?

HTTP (Hypertext Transfer Protocol) is the set of rules for transferring data between a web browser and a web server. It is the foundation of data communication on the web.

HTTP vs HTTPS

HTTPS is the secure version of HTTP. It encrypts data during transfer to protect it from being intercepted. Websites that handle sensitive data (like banks) must use HTTPS.

How it Works

The browser sends an HTTP request to the server. The server processes it and sends back an HTTP response — usually an HTML page.
