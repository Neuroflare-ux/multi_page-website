World Wide Web (WWW)

What is the World Wide Web?

The World Wide Web, commonly known as the Web or WWW, is a system of interlinked documents and resources accessed through the internet. It was invented by Tim Berners-Lee in 1989.

How it Works

The web uses HTTP to transfer web pages written in HTML. When you type a web address into a browser, the browser finds the page on a server and displays it on your screen.

Key Facts

The first website ever created was at CERN in 1991. The web is not the same as the internet — the internet is the network, while the web is a service that runs on it.
